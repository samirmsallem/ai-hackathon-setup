# Hybrid

**Idea:** A deliberately named mix of methods, e.g. spec-driven for planning plus test-driven for implementation plus reviewer agent.

## Workflow
1. Write the mix as one sentence in `.hackathon/METHOD_LOG.md` before starting.
2. Assign each method to a phase.
3. Record whether each phase followed its method.

## Suggested agents / skills
Any.

## Checkpoints (for Supervised autonomy)
At each phase boundary.

## Watch out for
Hard to attribute success. Name which part you expect to help most and check it afterwards.

## Document in METHOD_LOG
What you changed from this recipe and why.
