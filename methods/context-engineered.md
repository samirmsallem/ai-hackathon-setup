# Context-engineered

**Idea:** Treat the context window as the scarce resource: small focused sessions, written notes, explicit hand-offs.

## Workflow
1. Create `.hackathon/context/NOTES.md` (decisions, open questions, next step).
2. Work in short sessions per module (core, API, UI); start each with only the relevant files.
3. End each session by updating NOTES.md; clear/restart the chat.
4. Keep AGENTS.md short.

## Suggested agents / skills
Frameworks: GSD, Spec Kit. Skills: `plan-feature`.

## Checkpoints (for Supervised autonomy)
At each session boundary.

## Watch out for
Notes becoming a second spec. Keep NOTES.md under one page.
