# Skills-based

**Idea:** Use the reusable skills in `skills/` (and optional framework skills) as the unit of process.

## Workflow
1. `plan-feature` -> 2. `generate-tests` -> 3. `implement-feature` -> 4. `review-code` -> 5. `validate-acceptance` -> 6. `prepare-demo`.

## Suggested agents / skills
Skills: all six in `skills/`. One agent invokes them in order.

## Checkpoints (for Supervised autonomy)
After each skill finishes.

## Watch out for
Skills used mechanically without checking their output. Review each skill's artifact.
