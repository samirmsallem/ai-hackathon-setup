# Scorecard (facilitator + team self-assessment)

Total 100 points. Learning matters more than speed: process and insight carry 40 points.

| Category | Points | Evidence |
| --- | --- | --- |
| Acceptance: scenarios correct (AC-1..4) | 20 | `npm run validate` |
| Working UI and API (AC-6..8) | 15 | demo |
| Quality: lint, tests, build, readable code (AC-9) | 10 | scripts, review |
| Extendability and docs (AC-10) | 10 | README, architecture |
| Integrity: immutable files untouched, no hand-coding (AC-11) | 5 | git diff, intervention log |
| Method clarity: stated hypothesis and whether it held | 10 | METHOD_LOG |
| Intervention quality: logged, meaningful, effective | 10 | INTERVENTION_LOG |
| Insight: honest reflection, comparison, recommendation | 10 | presentation |
| Presentation | 10 | 5-minute talk |

Efficiency metrics (not scored, shown side by side): time to first green scenario, time to full validation, interventions per phase, method changes, tokens or premium requests if available.
