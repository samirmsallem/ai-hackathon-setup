# Presentation (5 min + 2 min questions)
1. **Team, tool, method, framework, autonomy** (30 s)
2. **Hypothesis:** why we expected this method to work
3. **Timeline:** key phases and method changes (use METHOD_LOG)
4. **Result:** scenarios passing, UI demo (live, 90 s)
5. **Interventions:** count by type, the 2 most important ones, one we regret
6. **What the method did well / badly**
7. **Would we repeat it? What would we change? Recommendation for others**
8. **Next steps to extend the prototype**
