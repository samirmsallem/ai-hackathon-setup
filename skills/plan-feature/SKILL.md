# plan-feature

1. Read `challenge/requirements.md`, `acceptance-criteria.md`, `AGENTS.md`.
2. Produce `.hackathon/plan.md` as a checklist of tasks of at most 15 minutes each, ordered core -> API -> UI -> docs.
3. Each task names the acceptance criteria it advances and the command that proves it.
4. List risks and the first three tasks. Keep the plan under one page.
5. Stop and present the plan for approval (unless autonomy is Maximum, then continue).
