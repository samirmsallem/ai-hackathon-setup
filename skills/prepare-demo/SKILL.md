# prepare-demo

1. Run `npm run validate` one last time and verify `npm run demo` works from a clean terminal.
2. Write a 90-second demo script: which scenarios to show (normal vehicle, contradictory data, critical
   combined, custom JSON) and what to point out in each.
3. Write `.hackathon/presentation.md` for a five-minute talk, using `.hackathon/session.json`: the chosen
   configuration, what the method did well, where it cost time, the honest percentage of acceptance
   criteria met, and one recommendation for the next team.
4. Make sure `README.md` is accurate (setup, usage, architecture, how to extend) and list next steps.
5. Commit everything on the team branch.
