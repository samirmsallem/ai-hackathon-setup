# GitHub Spec Kit

Spec-driven development: constitution, specify, plan, tasks, implement slash commands that keep a living spec in the repo.

## Fit for this challenge
Best match for the Spec-driven method.

## Install
See `frameworks/catalog.yaml` entry `github-spec-kit`. Always confirm with the team before running installers.

## Reduced path for 120 minutes
Constitution (use AGENTS.md rules) -> specify (paste challenge/requirements.md) -> plan -> tasks -> implement. Skip clarify loops beyond one round.

## Risks
Needs uv/Python and network. The generated spec duplicates challenge/ - treat challenge/ as the source of truth.

## What to log
Framework setup time, any interventions caused by the framework (e.g. dead-end prompts), and any commands you skipped.
