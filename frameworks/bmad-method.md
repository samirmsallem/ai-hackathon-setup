# BMAD Method

Agile-persona framework: analyst, product manager, architect, scrum master, developer and QA agents producing PRD, architecture and story files.

## Fit for this challenge
Possible but heavy. Only for teams that want to study full agile ceremony against a tiny scope.

## Install
See `frameworks/catalog.yaml` entry `bmad-method`. Always confirm with the team before running installers.

## Reduced path for 120 minutes
Skip analyst/brief phases (the challenge is already defined). Start from architect, then stories, then dev/QA.

## Risks
Document generation can consume 40+ minutes. Set a hard stop at minute 35 for planning.

## What to log
Framework setup time, any interventions caused by the framework (e.g. dead-end prompts), and any commands you skipped.
