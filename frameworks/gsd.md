# GSD (Get Shit Done)

Context-engineering workflow: phases, fresh-context executor agents, and atomic commits to avoid context rot.

## Fit for this challenge
Best with Context-engineered and Multi-agent methods.

## Install
See `frameworks/catalog.yaml` entry `gsd`. Always confirm with the team before running installers.

## Reduced path for 120 minutes
Use a single milestone with 3 phases: core engine, API, UI.

## Risks
Check upstream for the currently maintained package; the name or install command may have changed.

## What to log
Framework setup time, any interventions caused by the framework (e.g. dead-end prompts), and any commands you skipped.
