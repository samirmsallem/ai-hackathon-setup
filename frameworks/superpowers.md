# Superpowers

A skills-based workflow that pushes the agent through brainstorming, written plans, subagent-driven execution, TDD and code review.

## Fit for this challenge
Strong with Multi-agent and Test-driven methods.

## Install
See `frameworks/catalog.yaml` entry `superpowers`. Always confirm with the team before running installers.

## Reduced path for 120 minutes
Skip long brainstorming: give it challenge/requirements.md as the finished brief and go straight to planning.

## Risks
Can over-plan for small tasks. Watch the clock; set a 15-minute planning budget.

## What to log
Framework setup time, any interventions caused by the framework (e.g. dead-end prompts), and any commands you skipped.
