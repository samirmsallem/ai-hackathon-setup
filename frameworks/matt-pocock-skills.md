# Matt Pocock Skills

Composable skills for real engineering work: alignment interviews (grilling), TDD, diagnosing problems, PRDs and issues. Skills are plain markdown, so they work with several agents.

## Fit for this challenge
Strong with Skills-based, Test-driven and Context-engineered methods. Low overhead.

## Install
See `frameworks/catalog.yaml` entry `matt-pocock-skills`. Always confirm with the team before running installers.

## Reduced path for 120 minutes
1. Install. 2. Run the setup skill once (choose a local-file issue tracker; no GitHub needed). 3. Use the grilling skill for 5 min on the requirements, then the TDD skill for implementation.

## Risks
Setup skill may ask about GitHub remotes - choose local files. Do not let it create docs outside docs/ or .hackathon/.

## What to log
Framework setup time, any interventions caused by the framework (e.g. dead-end prompts), and any commands you skipped.
